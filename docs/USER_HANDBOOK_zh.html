01开始使用

前置条件（CLI 安装）

  • Windows / Linux / macOS
  • Python 3.12+

从 GitHub 安装

uv tool install -q --python 3.12 git+https://github.com/JZKK720/agent-meow.git

或使用 pip：

pip install git+https://github.com/JZKK720/agent-meow.git

然后，一次性配置可选的文档转换与办公工具（详见 §4.6）：

# markitdown — 将 HTML/PDF/DOCX/XLSX/PPTX 转换为 Markdown
uv tool install "markitdown[all]"

# officecli — 创建/编辑/导出真实的 Word/Excel/PowerPoint 文件
# 从 OfficeCLI 发布页下载 officecli-win-x64.exe，并放置到
# ~/.local/bin/officecli.exe
注意

PyPI 包名为 omnigent（模块目录为 agent_meow/）。CLI 入口 omnigent、omni 与 agent-meow 可互换使用。

02以正确方式启动服务器

agent-meow 在 http://127.0.0.1:6767 上运行一个后台本地服务器，提供 Web UI 与 REST API。始终使用托管启动器，这样服务器能在会话间持久存在，并被 CLI 复用。

方案 A——持久化启动器（推荐，Windows）

scripts/start-server.ps1 会设置所有必需的环境变量（HERMES_API_KEY、MARKITDOWN_BIN、OFFICECLI_BIN），并通过托管路径启动服务器，然后验证其健康状态：

powershell -ExecutionPolicy Bypass -File scripts/start-server.ps1
  • 首次运行 / 配置变更后——添加 -Restart 先停止任何旧服务器，再全新启动：
powershell -ExecutionPolicy Bypass -File scripts/start-server.ps1 -Restart
  • 它是幂等的：如果健康服务器已启动，会打印 Background server already running 并复用。

启动器设置了什么

变量值原因
HERMES_API_KEY（你的网关密钥）认证到 Hermes 网关
MARKITDOWN_BIN~/.local/bin/markitdown.exe让 doc_convert 找到 markitdown
OFFICECLI_BIN~/.local/bin/officecli.exe让办公文档工具找到 officecli
PYTHONUTF8 / PYTHONIOENCODING1 / utf-8日志中正确显示中文

方案 B——内置管理子命令

agent-meow server start    # 确保后台服务器运行（复用健康实例）
agent-meow server status   # 是否启动？端口 / pid / 会话？
agent-meow stop            # 停止服务器 + 本地主机守护进程
重要

不要运行裸的 agent-meow server（前台）做长时间工作——前台子进程会随终端一起消亡。请使用 server start，这样后台服务器会被分离、注册到 pidfile（~/.agent-meow/local_server.pid），并在终端清理后存活。

验证健康状态

agent-meow server status
# Background server: running at http://127.0.0.1:6767 (pid …, port 6767)

或访问健康端点：

curl http://127.0.0.1:6767/health     # → {"status":"ok"}
curl http://127.0.0.1:6767/v1/stack/status
# → server=ok hermes=ok ollama=ok tts=ok …

03打开并浏览应用

在浏览器中打开 http://127.0.0.1:6767（或打包的应用窗口）。

右侧工作区栏为每个界面提供标签页：

Files │ Docs │ Notes │ Snippets │ Images │ Videos │ Projects │ Voice │ Subagents │ Terminals │ Todos │ Browser
  • 点击标签页打开对应面板（如 Docs、Images、Videos）。
  • 输入框上方的起始标签是快速启动提示。
  • 选择一个智能体和一个工作区——一旦会话绑定到工作区，界面面板即变为可用。

在移动设备上，打开 http://<你的笔记本IP>:6767。

04文档

Docs 面板管理富文本与办公文档。用它来创建、转换、编辑和导出文档。

4.1 创建文档

两种方式：

  • 在聊天中：输入自然语言请求，例如 Create a meeting-notes doc titled "ABC Sync" with an agenda section. 智能体会调用 doc_create / doc_generate 工具。
  • 在 Docs 面板：使用创建按钮 / 提示种子生成文档。

4.2 列出并打开文档

Docs 面板列出你会话中的文档（最新在前）。点击一个即可打开富文本编辑器。

4.3 将任意文件转换为 Markdown（doc_convert）

使用 markitdown 将 HTML/PDF/DOCX/XLSX/PPTX 文件转换为 Markdown：

Convert docs/report.docx to Markdown and show the result

这会运行 doc_convert 工具。需要 markitdown（在 §4.6 安装）。确保设置了 MARKITDOWN_BIN（启动器会为你设置）。

4.4 创建真实的 Office 文件（doc_create_office）

创建原生 Word/Excel/PowerPoint 文件：

Create a .docx instruction sheet titled "Onboarding" with sections:
- Welcome
- First steps
- Contacts

这会运行 officecli 构建真实的 .docx/.xlsx/.pptx，然后上传到你的 Docs 面板。需要 officecli（在 §4.6 安装）。

4.5 编辑 / 导出 Office 文件（doc_edit_office、doc_export）

  • 编辑现有办公文档：Edit the "Onboarding.docx" doc — add a "Troubleshooting" section before "Contacts".
  • 导出为 PDF、HTML、PNG 或文本：Export the "Onboarding.docx" to PDF.

4.6 安装 Office 与转换 CLI

agent-meow 调用两个外部 CLI。两者都是可选的，但能启用完整的办公文档功能集。

markitdown（文档/核心格式 → Markdown）：

uv tool install "markitdown[all]"
# → 将 markitdown.exe 安装到 ~/.local/bin/

officecli（创建/编辑/导出 Word/Excel/PowerPoint）：

  1. 从 OfficeCLI 发布页下载 officecli-win-x64.exe。
  2. 放置到 ~/.local/bin/officecli.exe。
  3. 验证：officecli --version → 1.0.147。

因为 ~/.local/bin 通常不在 PATH 上，工具默认找不到它们。设置环境变量（启动器会这样做）：

$env:MARKITDOWN_BIN = "$env:USERPROFILE\.local\bin\markitdown.exe"
$env:OFFICECLI_BIN  = "$env:USERPROFILE\.local\bin\officecli.exe"
注意

officecli 运行一个常驻进程，会保持文件句柄打开。agent-meow 现在会在读取/上传前调用 officecli close <file>，这会刷新并释放文件——修复了 Windows 的「文件被占用」（WinError 32）错误。你无需做任何事；它已被处理。

05图片

Images 面板是会话图片的图库。用它来上传、生成、编辑和打标签。

5.1 上传 / 列出图片

将图片拖入面板或通过按钮上传。图片按最新在前列出。

5.2 生成图片

使用 Images 面板中的 Generate 按钮（或提示种子）——智能体会运行图片生成提供商（fal / DashScope，在 设置 → 媒体与生成 下配置），并自动将结果上传到图库。

Create a wide hero image of a sunset over a calm sea.

5.3 编辑图片

image_edit 支持背景移除（rembg）、调整大小等操作。在聊天中询问智能体：

Remove the background from the photo "beach.png".

5.4 由 LLM 自动打标签（image_analyze）

智能体的视觉模型对图片分类，并调用 image_analyze 为该文件存储小写、去重的标签（最多 10 个，每个 ≤20 字符）。这些标签为文件/EXIF 搜索（§7）提供支持。

06视频

Videos 面板是会话视频的图库。

  • 上传视频文件，或通过 Generate 按钮生成一个（例如 fal / Pixelle / DashScope / Hyperframes 提供商）。
  • 在面板中播放任何列出的视频。
  • 当智能体生成视频时，视频会自动出现在面板中。

07文件 + EXIF 自动搜索与排序

这是「文件智能」功能：agent-meow 自动索引工作区，从图片中提取 EXIF/日期/相机元数据，并让你按内容搜索和排序——包括按 LLM 生成的标签。

工作原理（管线）

你向工作区放入一个文件 ↓ 文件监视器检测到它 → 加入文件索引队列 ↓ 元数据工作器提取（无需 LLM，始终可用）： images → Pillow EXIF（拍摄日期、GPS、相机品牌/型号、镜头、 尺寸、方向）+ 感知 dHash + WebP 缩略图 docs → 文本摘录 + 页数/字数 + SHA-256 other → 大小/修改时间 + SHA-256 ↓ 嵌入工作器（可选）添加 CLIP 视觉嵌入，用于「按语义搜索」 ↓ file-index + file-search 端点让一切可搜索

按关键词 / EXIF / 内容搜索

使用 Files 面板中的搜索框，或在聊天中询问：

Find my photos taken with the Sony camera
Find images from last week
Find the file about "quarterly report"

搜索是全文（FTS5 配合三元组分词器——因此也能匹配中文子串），针对 basename + kind + EXIF 相机/日期 + 文档文本摘录 的混合内容。在有 CLIP 服务器时，它还会合并视觉搜索（「按语义」搜索，例如「sunset at the beach」且无关键词重叠），通过倒数排名融合。

按 LLM 标签排序

智能体通过 image_analyze 写入 LLM 生成的标签。/tags/by-file 端点按文件提供这些标签，因此 Images 面板可以在每个缩略图上显示「这是什么」标签。所以：

  1. 智能体分析图片并打标签（例如 sunset、beach、ocean）。
  2. 面板显示这些标签。
  3. 你可以按标签查找图片。

索引存放在哪里

文件索引存储在共享的 chat.db（~/.agent-meow/）中，文件监视器索引运行器的全局工作区（例如 ~/agent-meow-workspace）。每个会话的工作树由回合后的工作区扫描索引。

注意

管线会优雅降级：如果 watchdog/Pillow 或 CLIP 服务器未安装，它会无操作或回退到仅 FTS——绝不会崩溃。

08笔记与代码片段

两个轻量级的右侧栏工具，用于快速记录。

笔记

  • 从 Notes 面板添加笔记（标题 + 正文，可选标签）。
  • 置顶笔记使其保持在顶部——右键 / 置顶操作。
  • 笔记按会话持久保存。

代码片段

  • 保存代码片段（标题、语言、代码、可选描述/标签）。
  • 按关键词搜索片段（/snippets/search）。
  • 在聊天中复用已保存的片段。

09语音管线——与智能体对话

用麦克风与智能体对话。管线完全本地化——无云端 STT/TTS。

🎤 麦克风 → Silero VAD（检测语音）→ Whisper（STT，转写） → 智能体回合 → Qwen3-TTS（语音）→ 扬声器 🔊
  • 点击 麦克风 / 爪印按钮（或使用唤醒词）开始语音回合。
  • ComposerMicButton / VoicePawButton 显示语音状态。
  • 智能体说话时会出现语音波形。
  • STT 默认为中文（zh）；浏览器会发送按请求的语言，可覆盖为英文。
提示

如果语音回复无声，请检查 设置 → 运行时状态——它会显示服务器、主机守护进程、Hermes、Ollama、STT 和 TTS 服务的实时健康状态，并带有进程指标（PID、运行时长、重启次数）。

10常见问题排查

服务器「在会话之间不断停止」

你可能在运行前台的 agent-meow server。请改用托管路径——持久化启动器或 agent-meow server start：

powershell -ExecutionPolicy Bypass -File scripts/start-server.ps1 -Restart

doc_convert 提示「markitdown CLI not found」

markitdown 已安装但不在 PATH 上。设置 MARKITDOWN_BIN：

$env:MARKITDOWN_BIN = "$env:USERPROFILE\.local\bin\markitdown.exe"

（或运行启动器，它会设置。）

doc_create_office / doc_edit_office 提示「officecli CLI not found」

officecli 未安装或未找到。安装它（§4.6）并设置 OFFICECLI_BIN，或运行启动器。

Office 文档创建/编辑失败并提示「文件被占用」（WinError 32）

已在代码中修复——agent-meow 现在会在读取前调用 officecli close <file> 释放文件句柄。如果仍出现，请确保你在最新的 main（git pull）。

堆栈显示 hermes: auth_error / 401

Hermes 网关密钥错误。实时密钥在网关的 /opt/data/.env（API_SERVER_KEY=…）。在启动服务器前将 HERMES_API_KEY 设为该值（启动器会这样做）。

EXIF 搜索无结果

  • 确认文件在已索引的工作区（全局工作区）中。
  • 给监视器一点时间——提取在约 2 秒的工作器周期上运行。
  • 确保文件确实已索引（不是 pending/failed）。

STT 将英文转写为中文

当 STT 默认语言为 zh 时属预期。发送按请求的语言 en（浏览器客户端会自动为英文语音这样做）。
