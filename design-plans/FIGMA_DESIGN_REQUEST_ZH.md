# Figma 设计需求清单 — agent-meow UI

**日期：** 2026-07-24 · **来自：** agent-meow 工程团队 · **致：** Figma 设计团队
**目的：** 完整梳理 agent-meow 产品 UI 所需的 Figma 设计资产清单

---

## 设计定位

> 定位为：面向开发者和高级用户的**多界面 AI 智能体工作空间**，采用 **ColorFire 烬橙** 品牌语言，基于 **Tailwind v4 + Radix UI + shadcn** 技术栈，搭配暖色暗黑玻璃拟态风格。

**当前设计系统：**
- **品牌：** ColorFire（智方云）— 烬橙 (`#E8651A`)，暖琥珀点缀 (`#FFB347`)，暖暗画布 (`#1A1410`)
- **字体：** 系统无衬线体（San Francisco/Segoe UI/Roboto）+ Geist Mono 代码字体
- **组件库：** Radix UI 原语 + shadcn 封装
- **主题：** 浅色（暖白 `#FFFBF5` 画布）+ 深色（暖暗 `#1A1410` 玻璃拟态）
- **圆角：** `0.5rem` 基准，通过 Tailwind `--radius-*` 缩放
- **图标集：** Lucide React（描边宽度 1.5）
- **吉祥物：** MeowCat（橘宝疾风）— 几何猫剪影，带眼球追踪动画

## 优先级排序

1. **MeowCat 吉祥物**（完整角色）— 应用图标、启动页、加载状态所需
2. **应用图标**（全平台）— Electron/iOS/Android 打包所需
3. **落地页主视觉** — 第一印象，需设计构图
4. **工作面卡片图标**（文档/图片/视频）— 当前使用通用 Lucide
5. **空状态插画** — 当前仅文字
6. **框架/智能体类型图标** — 当前使用文字徽章
7. **移动端布局** — 验证当前响应式行为是否符合设计意图
8. **动效规范** — 记录现有动画的时间/缓动

## 不需要的内容

- 新的组件库（我们使用 Radix + shadcn）
- 新的 CSS 框架（我们使用 Tailwind v4）
- 新的图标集（我们使用 Lucide，只需品牌补充）
- 新的字体系统（我们使用系统 UI + Geist Mono）
- 仪表盘/数据表格设计（这是聊天工作空间，不是分析工具）
